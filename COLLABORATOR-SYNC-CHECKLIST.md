# OneNation VC Hub — Collaborator Sync Checklist

1. Open https://github.com/onenationsvg/onenationsvg
2. Confirm you are using the `main` branch for the current baseline.
3. Pull/download the current repository before editing.
4. Confirm the brand direction is **D**.
5. Confirm the tagline is **Unity • Culture • Progress**.
6. Use the repository `assets/` directory as the current shared asset set.
7. Do not publish an older local/ZIP copy over the live site.
8. Submit meaningful changes for review/merge into `main`.
9. After a merge, sync your workspace again before starting the next task.
10. If you have newer work that is not in `main`, preserve it separately and identify it for review rather than overwriting current files.
