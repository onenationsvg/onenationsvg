# OneNation VC Hub — Master Project Hub

**Brand direction:** D  
**Tagline:** Unity • Culture • Progress  
**Working principle:** One shared vision, with contributions brought together transparently.

This document is the starting point for navigating the OneNation VC Hub project. The GitHub repository's `main` branch is the shared reference point for project files and approved documentation.

## Official project links

- Canonical production website: https://www.onenationsvg.dpdns.org/
- Root production domain: https://onenationsvg.dpdns.org/
- Cloudflare Pages preview: https://onenationsvg-git.pages.dev/
- Legacy Pages endpoint (not for promotion or release): https://onenationsvg.pages.dev
- Source repository: https://github.com/onenationsvg/onenationsvg

These links are recorded project references; their current availability and deployment status should be checked before making release announcements.

## Project areas

1. **Website** — preserve the existing static HTML, CSS, and JavaScript experience, navigation, galleries/lookbook, apparel content, WhatsApp contact path, and Metricool-related elements.
2. **Brand identity** — use direction D and the tagline above as the current approved starting point. Keep earlier explorations available for reference rather than silently discarding them.
3. **Brand assets** — organize approved logos, marks, typography, color references, print-ready artwork, and supporting visual assets with clear filenames and version notes.
4. **Content and communications** — keep public-facing copy, social content, contact details, and campaign materials consistent with the master identity.
5. **Project operations** — record decisions, outstanding tasks, and release checks so contributors can work from the same information.

## Collaboration and change control

See [ONENATION-COLLABORATION-STANDARD.md](./ONENATION-COLLABORATION-STANDARD.md) for the shared contribution and synchronization process.

For now, collaborator onboarding remains optional and is not a blocker to project organization. Private files and local copies do not automatically synchronize with this repository.

## Practical next-stage checklist

- [ ] Confirm which brand marks and identity assets are approved for public use.

## Project integrity

- Do not overwrite or remove original assets during cleanup.
- Do not publish private contributor information or credentials.
- Do not claim a deployment, integration, or synchronization is complete until it has been verified.
- Record material decisions in the repository so the shared project history remains understandable.
