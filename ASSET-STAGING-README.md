# OneNation SVG — Asset Performance Staging

This branch is isolated from `main`. Nothing in this staging branch is published to the live website unless changes are reviewed and merged.

## Package to add

`OneNation_Website_Asset_Staging_Review.zip`

The review package contains 129 optimized WebP website images, contact sheets, an asset manifest, a summary, and review notes.

## Intended repository location

After the package is uploaded and extracted, place only the web-ready image derivatives under `assets/optimized/`, preserving their subfolders. Keep print masters outside the website asset directory.

## Current status

- Staging branch created from `main`.
- The optimized image package has not yet been uploaded to this branch.
- Existing website image references have not been changed.
- No production deployment or DNS changes are intended as part of this staging step.

## Review checklist

1. Upload and extract the review package.
2. Verify filenames and paths against the current website.
3. Check image loading in a branch preview.
4. Prepare a draft pull request for review.
5. Merge only after explicit approval.
