## Single source of truth

The `main` branch of this repository is the shared reference for approved website files and project documentation. Collaborators should sync from this repository before editing and submit changes back through a branch or pull request so changes can be reviewed and merged without overwriting one another.

Repository: https://github.com/onenationsvg/onenationsvg

## Approved project decisions

- Keep the project identity aligned with the approved direction D.
- Use the tagline exactly as written: **Unity • Culture • Progress**.
- Treat contributions from all collaborators as part of the shared OneNation effort.
- Preserve existing approved work. Do not replace or remove assets, pages, integrations, or content merely to make a local copy match.
- When a decision has not been approved or documented, flag it for collaboration rather than inventing a new standard.

## Collaboration and sync procedure

1. Before starting work, pull or sync the latest `main` branch.
2. Make changes on a dedicated branch; avoid editing the shared production branch directly where possible.
3. Keep filenames, navigation, brand wording, and shared assets consistent with the current repository.
4. Submit a pull request describing what changed and which pages/assets are affected.
5. Resolve conflicts against the latest approved version; do not silently discard another collaborator's work.
6. After a change is merged, each collaborator should sync their local copy again.
7. Keep project-specific working files in this repository or link them from a clearly maintained project index. Private copies in individual accounts are not automatically synchronized by GitHub.

## Current repository baseline

The root currently includes the website entry page, collection and copyright pages, shared assets, deployment notes, and collection update notes. The repository itself—not an older downloaded ZIP or an individual's local copy—is the baseline for current shared website work.
